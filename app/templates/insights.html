Conectar estadísticas de DSpace

El panel consulta la API REST desde Flask; las direcciones internas y las credenciales no se guardan en el navegador.

🔒
Solo lectura. Crea una cuenta de servicio con el mínimo acceso requerido. Las claves se guardan en el archivo local .env, nunca en el código ni en el navegador.

Configuración del repositorio

Válido para DSpace 9 y 10
Se configura en el servidor

En .env define DSPACE_REST_URL=https://tu-repositorio/server/api. Si las estadísticas requieren autenticación, configura también DSPACE_EMAIL y DSPACE_PASSWORD. Reinicia Flask después de guardar.

Qué consulta el conector
  1. Conteos de ítems y colecciones mediante la API REST.
  2. Visitas, descargas e informes mensuales mediante los reportes de uso de DSpace.
  3. Envíos pendientes cuando la cuenta configurada tiene permiso.
